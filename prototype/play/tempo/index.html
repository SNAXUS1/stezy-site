What TEMPO changes while it's on. Every change is written down first and put back the moment it turns off, even after a crash. Nothing is ever closed.

Apps step backBackground apps get lower priority and Windows' efficiency mode while you play, picked by TEMPO or by you. Music, voice and anything your game needs are never touched.
Game firstYour game gets the processor before other apps.
Windows Game ModeWindows puts the game first and holds back updates and notifications.
Pause background recordingThe Xbox Game Bar's always-on recording stops while you play.
High performance powerYour processor stays at full speed. Skipped on battery.
Free memory when it runs shortWhen memory is nearly full, the apps that stepped back hand some of theirs back, so the game doesn't stutter while Windows reads from the drive. They keep working. Not a "RAM cleaner": it only acts when memory really runs short.
Game on the strong graphics cardOn laptops and PCs with two graphics chips, Windows sometimes runs a game on the weak built-in one. This makes the game use the strong one. Needs one session first, so TEMPO knows the game's exe.
